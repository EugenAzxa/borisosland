# Инвест 47 - сайт земельных участков

Главная: пролёт камеры с неба (по пути видны метки всех объектов) к посёлку у трассы Кола, затем дорога с 12 объектами Инвест 47 и раздел «О компании». Ещё на сайте витрина проверенных участков, блог и админка. Форм на сайте нет: связь только по телефону +7 911 090-47-47.

## Что где

- `public/` - всё, что отдаётся как есть: `index.html` (главная), `assets/` (css, js, картинки, кадры пролёта), а также страницы, которые собирает `scripts/build.mjs` (блог, «Продать участок», админка, robots.txt).
- `api/` - серверные функции Vercel:
  - `photo.js` - загрузка фото к участку (только из админки);
  - `admin.js` - админка;
  - `vitrina.js` - страницы витрины, собираются на сервере для поисковиков;
  - `img.js` - фото из хранилища;
  - `sitemap.js` - карта сайта.
- `lib/` - общий код: шапка и подвал (`site.js`), витрина и свои участки (`listings.js`), хранилище (`store.js`), вход в админку (`http.js`).
- `content/blog/*.md` - статьи блога.
- `_src/` - исходники видео и кадров (не в git).

## Как править

- **Телефон:** `SITE.phone` и `SITE.tel` в `lib/site.js` (внутренние страницы), ссылки `tel:` в `public/index.html`, `PHONE` в `public/assets/js/site.js` (кнопки участков на главной). После правки запустить `npm run build`.
- **Объекты на главной (дорога, список, метки в пролёте):** `lib/objects.js`, картинки в `public/assets/img/obj/<img>.webp` и `<img>-s.webp` (640 px). После правки `npm run build`. Движок дороги - `public/assets/js/objects.js`.
- **Свои участки:** список `OWN` в `lib/listings.js` (витрина) и `PLOTS` в `public/assets/js/main.js` (генплан и пролёт).
- **Статья:** добавить `.md` в `content/blog` (формат как у соседних), затем `npm run build`, закоммитить и запушить.
- После правки `lib/site.js` (шапка, подвал) тоже запустить `npm run build`.

## Витрина

1. Владелец звонит и согласует размещение. Сам добавить участок на сайт он не может.
2. Инвест 47 заводит участок в `/admin` кнопкой «Добавить участок»: поля, фото, контакты владельца (на сайт не попадают) и отметки о том, что проверено. Пароль лежит в переменной `ADMIN_PASSWORD` на Vercel.
3. После «Опубликовать» участок появляется на `/vitrina` в течение минуты.
4. Данные хранятся в закрытом хранилище Vercel Blob `invest47-data` (Франкфурт).

## Локально

`npm install`, потом `vercel dev --listen 3077`. Пролёт без форм можно смотреть и так: `cd public && python3 -m http.server 8790`.

Деплой: push в `main`, Vercel собирает сам.

## Пролёт

- **Кадры:** `assets/film/d1` - 139 кадров по 1600 px для компьютера; `assets/film/m3` - 70 кадров по 720 px для телефона (центральные 80% кадра).
- **На телефоне:** кадры заранее распаковываются в ImageBitmap, иначе прокрутка дёргается.
- **Финальный кадр:** `assets/img/plan.webp`, на нём размечены участки (координаты 1400 x 791).
- **Откуда кадры:** Higgsfield. Ключевые кадры сделаны в GPT Image 2.5, переходы между ними в Seedance 2.5.

Данные участков взяты из объявления «Инвест 47» на Авито: участок 23,72 сот., 15 000 000 ₽, к/н 47:07:1047002:3249, 3250, 150 кВт, доля 4 сот. в общей дороге.
