# Инвест 47 - сайт земельных участков

Главная: пролёт камеры с неба к участкам промназначения на 6 км Мурманского шоссе. Ещё на сайте витрина проверенных участков с модерацией, блог, форма «перезвоните мне» и админка.

## Что где

- `public/` - всё, что отдаётся как есть: `index.html` (главная), `assets/` (css, js, картинки, кадры пролёта), а также страницы, которые собирает `scripts/build.mjs` (блог, форма подачи участка, политика, админка, robots.txt).
- `api/` - серверные функции Vercel:
  - `form.js` - формы «перезвоните мне» и «продать участок»;
  - `photo.js` - загрузка фото к заявке;
  - `admin.js` - админка;
  - `vitrina.js` - страницы витрины, собираются на сервере для поисковиков;
  - `img.js` - фото из хранилища;
  - `sitemap.js` - карта сайта.
- `lib/` - общий код: шапка и подвал (`site.js`), витрина и свои участки (`listings.js`), хранилище (`store.js`), токены и уведомления (`http.js`).
- `content/blog/*.md` - статьи блога.
- `_src/` - исходники видео и кадров (не в git).

## Как править

- **Телефон:** `PHONE` в начале `public/assets/js/site.js`. Пока он пустой, кнопки ведут к форме «Оставьте номер».
- **Свои участки:** список `OWN` в `lib/listings.js` (витрина) и `PLOTS` в `public/assets/js/main.js` (генплан и пролёт).
- **Статья:** добавить `.md` в `content/blog` (формат как у соседних), затем `npm run build`, закоммитить и запушить.
- После правки `lib/site.js` (шапка, подвал) тоже запустить `npm run build`.

## Витрина и заявки

1. Владелец заполняет `/vitrina/podat`, заявка уходит в закрытое хранилище Vercel Blob (`invest47-data`, Франкфурт).
2. В `/admin` (пароль в переменной `ADMIN_PASSWORD` на Vercel) заявку можно проверить, поправить текст, отметить, что проверено, и опубликовать.
3. Опубликованный участок появляется на `/vitrina` в течение минуты. Контакты владельца на сайт не попадают.
4. Обращения из всех форм видны в админке во вкладке «Обращения».

**Уведомления в Telegram:** задать на Vercel `TG_BOT_TOKEN` (бот от @BotFather) и `TG_CHAT_ID` (id чата; можно несколько через запятую), затем сделать redeploy.

## Локально

`npm install`, потом `vercel dev --listen 3077`. Пролёт без форм можно смотреть и так: `cd public && python3 -m http.server 8790`.

Деплой: push в `main`, Vercel собирает сам.

## Пролёт

- **Кадры:** `assets/film/d1` - 139 кадров по 1600 px для компьютера; `assets/film/m3` - 70 кадров по 720 px для телефона (центральные 80% кадра).
- **На телефоне:** кадры заранее распаковываются в ImageBitmap, иначе прокрутка дёргается.
- **Финальный кадр:** `assets/img/plan.webp`, на нём размечены участки (координаты 1400 x 791).
- **Откуда кадры:** Higgsfield. Ключевые кадры сделаны в GPT Image 2.5, переходы между ними в Seedance 2.5.
