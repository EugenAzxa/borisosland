# Инвест 47 - сайт земельных участков

Одностраничный сайт: пролёт камеры с неба (над облаками) к участкам промназначения на 6 км Мурманского шоссе. При прокрутке на землю ложатся крыша из логотипа, надпись «ИНВЕСТ 47» и разметка участков с генплана (8 проданы, 3 свободны).

Статика без сборки: открыть `index.html` через любой локальный сервер, например `python3 -m http.server 8790`.

## Что где

- `index.html` - разметка и тексты.
- `assets/css/style.css` - стили (тёмная тема, лаймовый цвет из логотипа).
- `assets/js/main.js` - пролёт на canvas, слой на земле, генплан, карточки участков.
- `assets/film/d1` - 139 кадров пролёта для компьютера (1600 px), `assets/film/m1` - центральная полоса для телефона.
- `assets/img/plan.webp` - последний кадр сверху, на нём размечены участки (координаты 1400 x 791).
- `assets/img/logo.svg` - логотип, перерисован в вектор.

## Как править

В начале `assets/js/main.js`:

- `CONFIG.phone` - телефон. Пока пустой: кнопки «Позвонить» ведут к блоку контактов.
- `PLOTS` - участки: площадь, цена, статус `sold`, пункты для карточки. Чтобы отметить участок проданным, поставить `sold: true`.

## Откуда кадры

Higgsfield: ключевые кадры GPT Image 2.5 (над облаками, 1500 м, 250 м сверху), переходы Seedance 2.5 (start/end image, 1080p, без звука). Исходники лежат в `_src/` (не в git).
